VELOMOTEUR V3 — VERSION SAFARI

Cette version est une PWA : elle peut être ouverte dans Safari puis ajoutée à l'écran d'accueil de l'iPhone.

Fonctions :
- vitesse GPS en temps réel
- distance
- vitesse moyenne et maximale
- chronomètre
- tracé/position sur carte OpenStreetMap
- régime moteur virtuel
- boîte automatique 6 rapports
- réaction du régime à la vitesse et à l'accélération
- son moteur synthétique
- profils 4 cylindres / V6 / V8
- réglage du régime maximal

INSTALLATION :
1. Héberger le dossier sur un site HTTPS.
2. Ouvrir l'adresse dans Safari sur l'iPhone.
3. Autoriser l'accès à la localisation.
4. Appuyer sur DÉMARRER.
5. Dans Safari : Partager → Ajouter à l'écran d'accueil.
6. Lancer VeloMoteur depuis l'icône comme une application.

IMPORTANT :
- Le GPS et les fonctions audio de Safari ont des limitations lorsqu'une page est en arrière-plan ou lorsque l'iPhone est verrouillé.
- Cette V3 est un prototype web ; le son est synthétique, pas un enregistrement d'un vrai moteur.
- Pour le GPS, utiliser HTTPS (sauf localhost).
